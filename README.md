# Mechtrophic

Playable browser build of **Mechtrophic**, a 10v10 mech battle game in a destructible voxel city.

**Play:** open the GitHub Pages link for this repository (Settings → Pages shows it, usually `https://<your-user>.github.io/mechtrophic/`).

This repository holds only the compiled build: `index.html` and the asset packs it loads (`hq/`, `hql/`, `menu/`, `radio/`, `vo/`). The game's source code is kept private and is not part of this repository.

## Playing

- Best on a desktop browser with WebGL 2 (Chrome, Edge, Safari or Firefox). Phones work in landscape.
- The first load is large (about 200 MB with the HD mech models and MechRadio), so give it a moment. Later visits load from the browser cache.
- WASD walks the legs, the mouse aims the torso, 1–4 and Space fire skills. Everything else in range inside the red auto-aim cone fires on its own.
